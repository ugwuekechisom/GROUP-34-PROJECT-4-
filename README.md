Grade Calculator Application

# This project is a simple Grade Calculator Application developed as a group project. It is designed to help users calculate students’ grades based on their scores and display the corresponding grade.

# Features

- Enter student scores
- Calculate students’ grades automatically
- Display the calculated grade
- Determine grades based on score ranges
- Show different grades such as A, B, C, D, and F
- Provide instant results
- Simple and user-friendly interface
- Prevent invalid or empty score entries

# Technologies Used

- HTML
- CSS
- JavaScript
